# Projektbeskrivelse

- Byg et responsivt website for fitnessbrandet FORM.
- Design og struktur skal følge det færdige Figma-design.
- Website skal indeholde:
    - Forside
    - Bliv medlem
    - Om os
    - Kontakt
- Desktop- og mobilversion skal følge de respektive Figma-layouts.
- Fokusér på tydelig brugerrejse, enkel navigation og begyndervenlig kommunikation.

# Teknologier

- Brug HTML5.
- Brug CSS3.
- Brug almindelig JavaScript.
- Brug semantisk HTML.
- Brug ikke frameworks eller eksterne biblioteker uden tilladelse.
- Brug ikke build tools, backend eller database.

# Projektstruktur

- HTML-filer skal ligge i projektets rod.
- Alt øvrigt materiale skal ligge under `assets/`.

Projektstruktur:

projekt/
├── index.html
├── membership.html
├── about.html
├── contact.html
└── assets/
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/

- Bevar denne struktur gennem hele projektet.
- Opret kun nye filer, hvis de er nødvendige.

# Arbejdsform

- Undersøg altid eksisterende filer og kode, før du ændrer noget.
- Følg projektets nuværende struktur og navngivning.
- Genbrug eksisterende HTML, CSS, JavaScript og komponentmønstre, hvor det giver mening.
- Lav så få ændringer som nødvendigt for at løse opgaven.
- Ændr ikke fungerende kode uden en konkret grund.
- Implementér ændringer systematisk og i små, kontrollerede trin.
- Følg Figma-designet så præcist som muligt.
- Hvis vigtig information mangler eller er uklar, skal du ikke gætte. Gør i stedet opmærksom på det.

# Andre vigtige ting i projektet

- Desktop-design tager udgangspunkt i en bredde på 1440 px.
- Mobil-design tager udgangspunkt i en bredde på 402 px.
- Brug følgende primære farver:
    - `#3E000C`
    - `#FFFFFF`
    - `#F3EDE7`
    - `#F1ECE6`
- Brug Manrope til overskrifter, navigation og knapper.
- Brug Inter til brødtekst og formulartekst.
- Primære CTA-knapper skal følge Figma-designet.
- Formularfelter og membership cards skal følge de mål og visuelle regler, der er defineret i Figma.
- Mobilnavigation skal bruge hamburger-menu.
- Footer skal være ensartet på alle sider.
- Responsivitet skal følge Figma-versionerne og ikke blot skalere desktop-layoutet ned.

# Begrænsninger

- Tilføj ikke frameworks eller biblioteker uden tilladelse.
- Tilføj ikke backend, database, login eller betalingsløsning.
- Omskriv ikke hele projektet, hvis en mindre ændring er nok.
- Ændr ikke filstruktur uden en konkret grund.
- Ændr ikke designretning, farver, typografi eller layout uden at det følger Figma eller en eksplicit instruktion.
- Opfind ikke funktionalitet, sider eller indhold, som ikke er efterspurgt.
- Gæt ikke på manglende krav.

# Test og kvalitet

- Kontrollér alle fire sider efter ændringer.
- Kontrollér både desktop- og mobilvisning.
- Kontrollér:
    - navigation
    - hamburger-menu
    - CTA-knapper
    - formularfelter
    - membership cards
    - billeder
    - footer
    - spacing
    - typografi
- Kontrollér at links mellem sider virker.
- Kontrollér at layout ikke overlapper eller bryder ved mindre skærmstørrelser.
- Brug passende HTML-elementer og labels i formularer.
- Gør opmærksom på relevante fejl, risici eller manglende information.
